Wix.com · IDOR Disclosure

An insecure direct object reference (IDOR) vulnerability discovered on Wix.com that allowed authenticated users to access user-scoped data through predictable endpoint identifiers without proper authorization checks.

TL;DR

Hacker Summary

An insecure direct object reference (IDOR) on Wix.com allowed access to user-scoped data through a predictable endpoint identifier. The vulnerability exposed user-controlled resources when accessed directly via URL manipulation. Reported through responsible disclosure; acknowledged by Wix.
